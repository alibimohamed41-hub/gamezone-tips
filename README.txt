GAMEZONE TIPS — 50 GAMES

Files:
- index.html — website structure
- style.css — black/neon responsive design
- script.js — 50 bilingual tips, search, categories, favorites and ratings

PUBLISH ON GITHUB PAGES USING ANDROID:
1. Download and extract GameZone-Tips.zip on your phone.
2. Open your GitHub repository in Chrome.
3. Open the repository file list and tap Add file → Upload files (or the + menu).
4. Upload index.html, style.css and script.js to the repository root. Do not upload only the ZIP.
5. Commit the changes.
6. Open repository Settings → Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose branch main and folder /(root), then Save.
9. Wait a minute or two. Open the URL shown in Settings → Pages; it usually looks like https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

IMPORTANT:
Favorites and ratings are stored in each visitor's browser (localStorage). They are not shared across visitors/devices, and can be removed if browser data is cleared. Shared public ratings require a backend/database such as Firebase or Supabase; GitHub Pages alone is static hosting.
The tips are general fan-made suggestions. Game names and trademarks belong to their respective owners.
